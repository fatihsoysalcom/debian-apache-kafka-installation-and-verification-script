# Debian Apache Kafka Installation and Verification Script

This Bash script automates the entire setup of Apache Kafka and Zookeeper on Debian-based systems. It installs Java, configures a dedicated system user, sets up systemd services, and verifies the installation by producing and consuming a test message.

## Language

`bash`

## How to Run

chmod +x install_kafka.sh
sudo ./install_kafka.sh
